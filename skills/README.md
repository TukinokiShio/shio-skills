# Skills

This directory contains the public skills in the collection.

| Skill | Best for |
| --- | --- |
| [first-principle](first-principle/) | When a problem is ambiguous, solution-led, or growing in scope. |
| [uncertainty-blindspot-audit](uncertainty-blindspot-audit/) | When an analysis or decision may depend on weak assumptions, missing evidence, or overlooked risks. |
| [reference-first-dev](reference-first-dev/) | Before starting a project or feature where proven solutions may already exist. |
| [inno-packager](inno-packager/) | When creating or diagnosing a Windows installer with Inno Setup 6. |
| [oq-governance](oq-governance/) | When material user decisions need to be captured and tracked across Markdown and JSON. |
| [course-outline-to-obsidian](course-outline-to-obsidian/) | When turning a course, textbook, or exam outline into navigable Obsidian notes. |
| [dependency-setup](dependency-setup/) | When a project is missing tools or dependencies and setup must be reviewed before installation. |

Each skill lives in its own folder and includes a `SKILL.md` with its purpose, trigger conditions, usage notes, and compatibility information. Open a skill's folder to read its documentation before installing it.
