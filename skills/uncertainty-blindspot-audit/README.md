# Uncertainty and Blind-Spot Audit

Use this skill after, or alongside, substantive analysis, planning, decisions, research, forecasts, diagnoses, reviews, or strategy work.

## What it does

It separates:

- the least-supported or most assumption-dependent judgment; and
- the important angle, failure mode, stakeholder, or second-order effect that may be missing.

Each finding is tied to evidence status and a minimal validation action. The audit is bounded: it supports the original task instead of replacing it with a generic risk list.

## Use it when

- evidence is incomplete, indirect, stale, or conflicting;
- a recommendation depends on hidden assumptions;
- you need to stress-test a plan or explanation;
- the cost of overlooking a failure mode is meaningful.

It is intentionally not used for casual conversation, routine formatting, or straightforward lookups.

## Compatibility

No extra dependency is required. The skill uses the current conversation, artifacts, sources, and available tools.
